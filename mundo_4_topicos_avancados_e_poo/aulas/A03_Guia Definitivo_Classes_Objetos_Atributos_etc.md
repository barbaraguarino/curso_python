# Guia Definitivo: Classes, Objetos, Atributos e etc

- O que é um **objeto**?
- O que é uma **classe**?
- Quando acontece um **instanciamento**?
- Sabe definir o **estado** de um objeto?

## Classe

- Um formato a ser seguindo sempre que precisar fazer um objeto do mesmo tipo, com as mesmas características ou com os mesmos comportamentos.
- A classe não é um objeto.
- As classes possuem três coisas que devem ser definidas: (1) Nome da classe; (2) Características que a classe tem, ou seja, atributos; (3) Coisa que a classe pode fazer, ou seja, métodos. 

## Instância

- Instanciar é seguir o padrão da classe para criar o objeto.
- O momento que a classe forma/constroi um objeto é instanciar uma classe. 

## Objeto

- Um objeto é a instância de uma classe.
- É uma coisa material ou abstrata que é feita a partir de um **modelo/classe** e pode ser descrita por meio das suas **características/atributos**, **comportamentos/métodos** e **estado atual**. 
- O **Estado Atual** são os conjuntos de valores de um objeto no momento. 

## Objetos Abstratos? 

- Uma **consulta** marcada no médico.
- Um processo de **venda**.
- Um **compromisso** ou **reunião**.
- Uma **aula** na faculdade.
- Uma **transição bancária**.
- Uma **reserva** de voo.
- Um **erro** do sistema.
